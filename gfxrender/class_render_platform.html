Detailed Description

Locates data and shader files that ship with GfxRender (Mesh sample .obj files; none of GfxRender's own shaders currently load their GLSL from files rather than inline C++ string literals, but FindGfxRenderShaderFile() remains available for anything that does).

Split out from Platform (which only knows generic, library-agnostic file-finding) since these paths – and the files they point to – are GfxRender's own, not GfxCore's.

std::string RenderPlatform::FindGfxRenderDataFile ( const std::string & basename)
static

Searches for a data file that ships with GfxRender.

This will look in the following locations in order:

  1. the current working directory.
  2. a subdirectory called data within the current working directory.
  3. the installed data directory INSTALL_PREFIX/share/GfxRender-1.0/data.
  4. the data directory in the GfxRender build tree. If the file is found, the full path is returned, else basename is returned.

std::string RenderPlatform::FindGfxRenderShaderFile ( const std::string & basename)
static

Searches for a shader file that ships with GfxRender.

This will look in the following locations in order:

  1. the current working directory.
  2. a subdirectory called shaders within the current working directory.
  3. the installed shaders directory INSTALL_PREFIX/share/GfxRender-1.0/shaders.
  4. the shaders directory in the GfxRender build tree. If the file is found, the full path is returned, else basename is returned.
