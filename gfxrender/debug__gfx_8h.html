Mesh BuildDebugLineMesh ( const std::vector< DebugLineSegment > & segments)

Builds a Mesh containing every segment in segments, each rendered as a thin quad (real triangle geometry, not a native GL_LINES primitive).

Every quad is double-sided by construction (both triangle windings are emitted), so the result draws correctly from any angle regardless of the caller's GL_CULL_FACE state – unlike a naively-wound single-sided quad, which would vanish from about half of all viewing angles depending on which way it happens to be facing. Each segment's color is baked directly into its own four vertices, so segments with different colors can be combined into one Mesh/one draw call – draw the result with DebugGfx::DrawLineMesh(), not directly with a shader, so those baked-in colors come through correctly. A segment with p0 == p1 (zero length) is silently skipped.
