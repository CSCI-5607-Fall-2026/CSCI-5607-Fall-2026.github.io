Detailed Description

Displays a fixed-pixel-dimension 2D canvas (via a Texture2D already holding its current contents) letterboxed/pillarboxed within a GraphicsApp's own content area – the drawable region of the window below any reserved toolbar strip (GraphicsApp::content_width()/ content_height()/content_viewport_top_inset()), which almost never has the same aspect ratio as the canvas itself.

Shown at the largest uniform scale that fits without cropping or distortion (a "contain" fit, via FitAspect()), centered, with the leftover margin on whichever axis doesn't exactly fit cleared to a fixed background color. Also converts between the window's own screen coordinates (top-left origin, matching mouse event coordinates) and canvas-pixel coordinates through that same fit, so a click anywhere in the letterbox margin simply maps outside [0, canvas_width] x [0, canvas_height] rather than needing special-casing.

A plain value type: build a fresh CanvasView everywhere it's needed rather than caching one, since the content area's own size can change (window resize) between one call and the next.

CanvasView view(canvas.width(), canvas.height(), 0.0f,
content_viewport_top_inset(),
static_cast<float>(content_width()),
static_cast<float>(content_height()),
content_framebuffer_width(), content_framebuffer_height());
view.DrawLetterboxed(canvas_tex, Color(0.15f, 0.15f, 0.15f, 1.0f));
