One square toolbar button (see ToolButton()) whose click reveals arbitrary ImGui content in a dropdown popup anchored directly below itself.

draw_icon draws the button's own icon; draw_popup_contents draws whatever the dropdown itself shows, called only on frames the popup is open – both are std::function so a caller can pass a capturing lambda straight through rather than a bare function pointer.

force_open re-asserts ImGui::OpenPopup() every frame instead of just the frame it's true: with no real mouse activity ever recorded in a headless run, ImGui's own popup-focus bookkeeping (which normally relies on that activity to decide whether a popup is still "in use") closes an unforced one again after just one frame.

◆ ToolButton()

Draws one square toolbar button (highlighted, via the same color ImGui already uses for a held-down button, when selected is true) and hands back its own center in screen coordinates, so the caller can immediately follow this with a few ImDrawList calls (via ImGui::GetWindowDrawList()) to draw that button's own icon on top – draw list commands execute in the order issued, so anything drawn right after this appears over the button ImGui::Button() itself just drew.

label is an ImGui ID only (every call site prefixes it with "##"); the icon is what the user actually sees, matching Unity's toolbar/ Photoshop's tool palette rather than a labeled button.
