Detailed Description

Includes the entire GfxCore library.

This is deliberately the math-free tier of the GfxCore/GfxMath/GfxRender split – GraphicsApp, Texture2D, Color, and Platform have no dependency on GfxMath, so an app that only needs these (e.g. Brush/Filter) can link GfxCore alone. Apps that also need Mesh, shaders, or 3D math should additionally include gfxmath.h and gfxrender.h.
