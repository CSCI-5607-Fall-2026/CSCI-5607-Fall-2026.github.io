Matrix4 Ortho2DProjection ( Point2 bottom_left,
Point2 top_right )

An alternative way to create a 2D orthographic projection matrix.

The location of the origin (0,0) is a common source of confusion when setting up these matrices, so this one's parameters require naming what the coordinate values should be at the bottom-left and top-right corners of the window.

// To place (0,0) in the bottom left corner of the screen use:
Ortho2DProjection(Point2(0, 0), Point2(window_width(), window_height()));
// To place (0,0) in the top left corner of the screen use:
Ortho2DProjection(Point2(0, window_height()), Point2(window_width(), 0));

Builders for the projection matrices that map a camera's view volume onto the clip volume OpenGL rasterizes against.

They are given rather than written in Algebra (2), where the rest of Matrix4 comes from: every one of them encodes a convention about where the near and far planes land in clip space, which is a rendering-pipeline fact rather than a linear-algebra one, and Algebra (2) has no camera yet to aim them with. They live here, alongside the rest of the rendering support, so they're available from Shapes (3) on – the first point a camera needs setting up.

Free functions rather than methods, because each constructs a Matrix4 out of plain numbers and has no state of its own to belong to. Returns a perspective projection matrix equivalent to the one gluPerspective creates.
