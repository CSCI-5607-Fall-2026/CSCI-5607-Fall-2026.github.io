Detailed Description

A wrapper around a 2D texture that supports loading images from files or setting texture color data directly.

Example:

Texture2D tex1;
Texture2D tex2(GL_CLAMP_TO_EDGE);
void MyGraphicsApp::InitOpenGL() {
std::vector<std::string> search_path;
search_path.push_back(".");
search_path.push_back("./data");
search_path.push_back("./shaders");
tex1.InitFromFile(Platform::FindFile("earth-2k.png", search_path));
tex2.InitFromFile(Platform::FindFile("toon-ramp.png", search_path));
}

◆ DrawFullscreen()

void Texture2D::DrawFullscreen ( ) const

Draws this texture as a single quad covering the entire current viewport, e.g.

to display a 2D image or PixelBuffer with no 3D scene involved. Call this from DrawUsingOpenGL() once the texture has been initialized.

This uses its own minimal, built-in shader rather than ShaderProgram, and needs no Matrix4 or other GfxMath type – deliberately, since Texture2D lives in GfxCore, which has no dependency on GfxMath. This is what lets Brush/Filter display their PixelBuffer without linking GfxMath or GfxRender at all.
