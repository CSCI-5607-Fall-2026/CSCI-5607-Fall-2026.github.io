Detailed Description

A material's shading properties – the same fields GfxRender's MaterialProperties has (see a consuming app's own ToMaterialProperties() for the conversion), plus a texture path rather than an already- loaded Texture2D, since this struct is meant to be plain, serializable data with no OpenGL state of its own. Named SceneMaterialDesc, not Material, so it doesn't collide with GfxRender's own Material class (a .mtl file loader/holder – see material.h) when both are visible in the same translation unit. mesh_file/texture are always bare filenames (never absolute paths), meant to be resolved against a search path built from the scene file's own location, so a scene and the files it references stay portable across machines and grading.
