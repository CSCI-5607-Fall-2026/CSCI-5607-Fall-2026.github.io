11// Portable stand-ins for GL_POINTS/GL_LINES -- both native primitives
12// have real, unresolvable portability problems in this codebase's
13// OpenGL 3.3 core profile target: glLineWidth > 1 is unsupported in
14// core profile on macOS and unreliable elsewhere, and GL_POINTS has the
15// same story for point size. So a visible debug point is a small
16// camera-facing quad ("billboard") and a visible debug line is a thin
17// quad running the segment's length -- both real triangle geometry,
18// drawn with the one UnlitShader DebugGfx owns internally.
