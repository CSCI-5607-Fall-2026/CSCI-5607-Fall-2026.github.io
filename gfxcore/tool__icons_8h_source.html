12// assignment, in one place, so no assignment's own panel/app code draws
13// raw ImDrawList primitives itself. Each function matches ToolIconDrawFn
14// (see tool_button.h) and can be passed directly to ToolButton()/
15// DropdownToolButton()/ToggleWindowPanelBase; coordinates are in the same
16// ToolIconPt()/kToolIconSize local space every one of them is built from.

23// ImDrawList has no native ellipse primitive -- approximate one by
24// sampling points on a manually x/y-scaled circle. Exported (not just an
25// internal helper of this file) since more than one assignment's own
26// icon needs an ellipse arc of its own (e.g. a3_shapes's own
27// DrawRotationIcon).

29 ImU32 color, float thickness, float a0 = 0.0f,
30 float a1 = 6.2831853f, int segments = 20);
