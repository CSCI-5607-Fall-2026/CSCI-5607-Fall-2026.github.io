std::string FormatSearchPathTooltip ( const std::string & description,
const std::vector< std::pair< std::string, std::string > > & tiers )

Formats description followed by a "Search Path:" list of numbered tiers – each a (label, resolved path) pair, e.g.

("${CURRENT_DIR}", cwd) – with every tier's own "N. ${label}:" column aligned to the longest label. Meant for an ImGui::SetItemTooltip()-style tooltip next to a load field/button, describing whichever search order that field's own loader actually uses.

Pass the result straight to ImGui::SetItemTooltip("%s", result.c_str()) – tiers are already-resolved strings, not a printf-style format plus args, so a path that happens to contain a literal '' is never misread as a format directive.
