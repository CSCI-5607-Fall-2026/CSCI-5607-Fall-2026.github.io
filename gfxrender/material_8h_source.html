11// A MaterialProperties, plus the ability to load one from a Wavefront
12// .mtl file -- the format used throughout gfx_libs/gfxrender/data (see
13// default.mtl and bmw.mtl), so an app can point a Material at any of
14// those and get matching Ns/Ka/Kd/Ks/map_Kd values, the same names
15// shown in a course-authored material panel and used by the shaders'
16// own uniforms. Kept separate from MaterialProperties itself (a plain
17// struct every shader's Draw() takes by const reference) so that
18// interface stays exactly as small as it's always been -- Material is
19// a loader/holder on top of it, not a replacement for it.
