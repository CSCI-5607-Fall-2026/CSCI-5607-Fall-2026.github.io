float BeginToolbar ()
 Begins the toolbar window itself: title-bar-less, non-resizable, non-movable, flush against the top of the display and spanning its full width, sized to fit exactly one row of kToolButtonSize icon buttons plus one row of small labels beneath them (see GroupLabel()). Pair with a plain ImGui::End() once the toolbar's own content is drawn. Returns the toolbar's own height – pass straight to the caller's own SetContentViewportTopInset() so whatever's drawn below doesn't extend a wasted sliver up behind this toolbar.
void GroupLabel (float start_x, float end_x, const char *label)
 Centers label under [start_x, end_x] (screen coordinates), on the label row directly beneath the toolbar's own icon-button row. Every GroupLabel() call belongs at the very end of a DrawGUI(), after every button in the toolbar has already been drawn – calling it any earlier would move what ImGui::SameLine() itself tracks internally as the "last item," breaking the horizontal flow of whatever button comes next.
float CenteredIconGroup (const char *label, const std::function< void()> &draw_button)
 Draws draw_button (any call that draws exactly one kToolButtonSize icon button) centered under whichever is wider, its own button or label's own text – so a label wider than one button (e.g. "Load PNG") doesn't spill its own centered GroupLabel() text into whatever comes next. Returns the x-coordinate (screen space) where the reserved group ends, for a matching GroupLabel() call at the end of DrawGUI().
float DrawSnapshotToolbarGroup (GraphicsApp *app, float *group_width)
 The "Save Snapshot" button a toolbar ends with, pinned flush against the toolbar window's own right edge (reserving at least label's own text width, the same way CenteredIconGroup() does) rather than continuing the normal left-to-right flow – draws GfxCore's own DrawSnapshotIcon() and calls app->RequestSnapshot() when clicked. group_width (out) is the reserved group's own width – a far-right group's start isn't known until this returns, so the caller needs it to build the matching end_x for its own GroupLabel("Save Snapshot") call. Returns the group's own start_x (screen space).
