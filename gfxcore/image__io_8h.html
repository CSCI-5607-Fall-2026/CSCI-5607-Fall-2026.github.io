unsigned char * LoadImageFileAsBytes ( const std::string & context,
const std::string & filename,
int * width,
int * height )

Decodes filename (PNG, JPG, and anything else stb_image supports) into a freshly allocated RGBA byte buffer – always 4 channels, regardless of the source file's own channel count – and writes its pixel dimensions into *width and *height.

Returns nullptr on failure, printing "<context>: File <filename> does not exist." or "<context>: Failed to load file <filename> - <reason>" to std::cerr itself; context names whichever caller is loading (e.g. "Texture2D"/"PixelBuffer"), so the message still identifies where a failure came from.

Free the returned buffer with FreeImageFileData() once done – it's allocated by stb_image, not operator new[], so delete[]/free() aren't safe to call on it directly.
