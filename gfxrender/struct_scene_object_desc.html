Detailed Description

One object in the scene: either one of the four canonical analytic primitives ("sphere"/"cube"/"cylinder"/"cone") or an arbitrary triangle mesh loaded from an .obj file (shape_type == "mesh", mesh_file set to that .obj's bare filename) – plus its full model transform and material. Mesh objects render through the same given Mesh::LoadFromOBJ() path every other assignment's given content already uses; the four primitive shape_types render through GfxShapes' MeshFactory_Sphere/Cube/Cylinder/Cone (Shapes (3)'s own content, forwarded from Camera & Shading (4) on – see each consuming app's own MeshForShape()).
